# saledock-b2b-product-data-skimmer-and-importer
Open-source Chrome/Edge (Manifest V3) extension for Saledock / Celerant ONE retailers. Hands-free B2B catalogue crawler, IndexedDB CSV deduplication &amp; barcode repair, per-supplier variant consolidation, bulk pack-size splitter, margin calculator, and automated Saledock Publish/OOSP back-office macro.
